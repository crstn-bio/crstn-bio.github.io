question: What would have to become possible before memory restoration is a real intervention?
mechanism: measure → decode → track → model → distinguish → intervene → restore
steps:
  - name: Measure
    text: signals at enough spatial and temporal resolution
  - name: Decode
    text: activity tied to specific memory states and processes
  - name: Track
    text: how representations change across encoding, consolidation and retrieval
  - name: Model
    text: participant-specific links between state, behaviour, context and intervention
  - name: Distinguish
    text: absent, degraded or inaccessible
  - name: Intervene
    text: does precisely timed perturbation change retrieval probability?
  - name: Restore
    text: "only then: can useful function be recovered, reproducibly?"
card:
  label: Clinical frontier
  status: frontier
  title: Alzheimer’s disease
  text: In mouse models of early Alzheimer’s, directly activating memory engram cells restored recall (Roy et al., *Nature* 2016). Whether anything comparable holds in people is unknown.
  note: Beyond neurodegeneration · reconsolidation · trauma · disordered memory
sources:
  - label: Roy et al., Nature 2016 · engram activation in Alzheimer’s mouse models
    url: https://www.nature.com/articles/nature17172
  - label: Josselyn & Tonegawa, Science 2020 · memory engrams
    url: https://www.science.org/doi/10.1126/science.aaw4325

Can we understand memory precisely enough to restore access to information the brain can no longer retrieve on its own? Not today. These are the problems in the way.
